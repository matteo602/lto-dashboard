Session Journey & Bet Attribution Funnel

Every session follows one mutually exclusive path from left to right, grouped first by Intent — what the user came to do — then by how the session actually began. Circle size is proportional to the number of sessions at that step, and connector thickness to the volume flowing between steps. Immediate means the bet was placed within the first two messages; Further Interaction means it took three or more. Responds to the period and brand selectors above.

Each person is counted once per node. A user active in two branches appears in both, so branch figures do not sum to the root total — the “% of all bets placed” shares are shares of the branch sum.
Session Journey & NO-Bet Attribution Funnel

The same Intent and Entry Type spine as the Bet funnel, but after Session Outcome it follows the sessions that did not bet — fanning each entry type into the five exit cohorts. Shows which entry types leak, and how they leak. Betting traffic only.

Each person is counted once per node in Unique Users mode.
Session Journey & EXIT Attribution Funnel

The same tree for sessions that ended without a bet. Cohorts are ordered by how close they came to converting. First-ever session means this was that user's first contact with the system; User later bet means that same user placed a bet in some other session, so the loss is recoverable. Betting traffic only — customer-support sessions are excluded.

In Unique Users mode each person is counted once per node — this is the view where the activation gap is starkest.
